# Security

This MVP uses synthetic data only. Do not commit `.env`, credentials, production customer data, or database files. Configure secrets through environment variables and a secret manager in deployment. The deterministic guardrails remain authoritative; optional Strands output is advisory only. Cognito authentication protects Ring account linking and device lookup, but the synthetic billing dashboard and its APIs are intentionally unauthenticated demo surfaces. Add application-wide authentication and authorization, rate limiting, TLS, managed persistence, and structured secret redaction before production use. SQLite persistence is suitable for this MVP but not a production multi-instance database.
